# glsl-playground

A clean-room, from-scratch re-implementation of the idea behind **[aaaa-zhen/glsl-playground](https://github.com/aaaa-zhen/glsl-playground)** by [@aaaa-zhen](https://github.com/aaaa-zhen). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
